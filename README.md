# REDS
Retrieval-Augmented and Debiased Sequential Recommendation with Heterogeneous Item Embeddings (REDS)
 
### Environments
* Python 3.7+
* PyTorch 1.12+
* CUDA 11.6+

### Run the code
```python run.py```
Specify the dataset in `config.yaml` will start automatic download.
